# Лабораторная работа №4 — Операционные системы

Вариант 2. Программа на C11 под Linux суммирует числа в дочернем процессе.

После окончания ввода `parent` запускает `child`. Числа и итоговая сумма передаются через временный файл, отображённый в обоих процессах с флагом `MAP_SHARED`. Потомок также записывает результат в файл, имя которого ввёл пользователь.

- `src/app/parent.c` и `src/app/child.c` содержат логику процессов.
- `src/os_api.h` и `src/os_api_posix.c` описывают общий буфер, отображение файла и запуск потомка.
- [run.md](run.md) содержит команды сборки и запуска, [отчёт](report/report.pdf) — описание алгоритма и листинг.
