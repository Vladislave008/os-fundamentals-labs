# Лабораторная работа №2 — Операционные системы

## Задача

Разработать программу из двух взаимодействующих процессов (`parent` и `child`), работающую
одинаково в Windows и Linux.

- `parent` считывает со стандартного ввода строки с числами с плавающей запятой и передаёт их
  `child` по первому анонимному каналу.
- `child` читает числа со стандартного ввода, накапливает сумму, записывает отчёт в заданный
  файл и возвращает итоговую сумму `parent` по второму анонимному каналу.
- `parent` выводит полученную сумму и ожидает завершения `child`.

Вся платформозависимость скрыта за единым кроссплатформенным API (`src/os_api.h`): реализации
на Win32 API (`src/os_api_win.c`) и POSIX (`src/os_api_posix.c`) выбираются при конфигурации CMake.
Логика приложений системных вызовов не содержит. Язык реализации — C (C11).

## Структура проекта

```
lab_2/
├── CMakeLists.txt            # выбор реализации API, сборка parent и child
├── README.md                 # этот файл
├── run.md                    # команды сборки и запуска
├── src/                      # кроссплатформенный интерфейс и его реализации
│   ├── os_api.h              #   единый API (типы os_pipe, os_process)
│   ├── os_api_win.c          #   реализация для Windows (Win32 API)
│   └── os_api_posix.c        #   реализация для Linux/Unix (POSIX API)
├── app/                      # прикладной уровень (без системных вызовов)
│   ├── parent.c              #   родительский процесс
│   └── child.c               #   дочерний процесс
├── docs/
│   └── report/               # отчёт по работе (LaTeX)
└── build-windows | build-linux # каталоги сборки (игнорируются git)
```

## Сборка и запуск

Команды и пути к бинарникам — в `run.md`. Отчёт в формате LaTeX собирается из `docs/report/`.
